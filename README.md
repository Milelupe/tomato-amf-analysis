# tomato-amf-analysis
# 🍅 Tomato-AMF Analysis

## Project Overview

This project investigates whether the origin of soil microbial communities influences the effectiveness of arbuscular mycorrhizal fungi (AMF) in improving tomato growth and reducing root-knot nematode infection.

The experiment was conducted under greenhouse conditions using a factorial experimental design.

---

## Biological Background

Arbuscular mycorrhizal fungi (AMF) establish symbiotic relationships with plant roots, improving nutrient acquisition and potentially increasing plant resistance against soil pathogens.

Natural soils are expected to harbor a more diverse AMF community than disturbed soils. This project evaluates whether differences in soil origin modify the protective effects of AMF against root-knot nematodes.

---

## Experimental Design

Factors:

- Soil origin
    - Natural
    - Disturbed

- AMF treatment
    - AMF inoculum
    - Microbial filtrate (non-mycorrhizal control)

- Nematodes
    - Present
    - Absent

---

## Response Variables

- Shoot biomass
- Root biomass
- Total biomass
- Mycorrhizal response
- Root colonization
- Number of galls
- Egg masses
